# 💻 ImmoEcu Pro v1.0

🚀 **Automated Web Platform for Automotive ECU Software Engineering**

**ImmoEcu Pro** is a specialized web-based application built with Python, designed for automotive technicians and ECU programmers. It provides instant, safe, and accurate processing of EEPROM and Flash dump files for **IMMO OFF** solutions and **PIN Code** extraction without byte shifting or checksum corruption.

🌐 **Live Demo:** [immoecu.onrender.com](https://immoecu.onrender.com)

---

## 🛠️ Supported ECU Families

### 🚗 Bosch (True Repair)
* **EDC15C2** (EEPROM + FLASH)
* **EDC16C34 / EDC16C3** (PSA)
* **EDC16C34 / EDC16C39** (Fiat)
* **ME7.4.4 / ME7.4.5** (Peugeot / Citroën)

### ⚙️ Valeo (Safe Modification)
* **Valeo V34** (EEPROM 4KB)
* **Valeo J34P** (EEPROM 2KB)
* **Valeo V46.11** (EEPROM 16KB)

### 🤖 Siemens, Marelli & Delphi (Dynamic Signature Search)
* **Siemens:** SID801 / SID801A / SID807EVO
* **Marelli:** 4MP2 / 48P2
* **Delphi:** DCM3.4 / DCM3.5 (EEPROM 8KB)

---

## ✨ Key Features
* **Zero Byte-Shifting:** Guarantees the structural integrity of binary dump files.
* **Fast Processing:** Instant server-side binary analysis and modification.
* **User-Friendly Interface:** Clean web dashboard accessible from any browser without complex software installation.
